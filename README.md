# 🧮 CNP Reader

A simple **C++ program** that reads and interprets a **Romanian Personal Numeric Code (CNP)**.

## 📘 Features

- Input a CNP from the user  
- Display:
  - Gender  
  - Year of birth  
  - Month of birth (full name)  
  - Day of birth  
  - County of origin  
- Validate that the CNP:
  - Has exactly 13 digits  
  - Contains only numeric characters  

## 💡 Possible improvements

- Add a function to calculate the person’s age
- Implement full CNP checksum validation
- Save results to a text file
- Add support for multiple stored CNP entries
- (Optional) Create a simple graphical interface
